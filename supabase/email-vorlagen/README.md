# Deutsche Mail-Vorlagen für Supabase

In Supabase unter **Authentication → Emails → Templates** einfügen:

| Vorlage in Supabase | Betreff | Datei |
|---|---|---|
| Confirm signup | Bestätige dein Konto bei der Playback Masterclass | `konto-bestaetigen.html` |
| Reset password | Neues Passwort für die Playback Masterclass | `passwort-zuruecksetzen.html` |
| Change email address | Bestätige deine neue E-Mail-Adresse | `email-aendern.html` |

Jeweils den Betreff in „Subject“ und den Inhalt der Datei in „Message body“ kopieren und speichern.
